# GY521-Lab

Aceleração em X, Y e Z
Velocidade angular em X, Y e Z
Temperatura interna

| Informação  | Unidade |
| ----------- | ------- |
| AccX        | g       |
| AccY        | g       |
| AccZ        | g       |
| GyroX       | °/s     |
| GyroY       | °/s     |
| GyroZ       | °/s     |
| Temperatura | °C      |
